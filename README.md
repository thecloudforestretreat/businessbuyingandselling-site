# businessbuyingandselling-site

Static public website and Cloudflare Pages Functions for Business Buying and Selling.

## Confidential listings

The repository includes anonymized public listing summaries, a staff admin dashboard, buyer/NDA pipeline APIs and a secure buyer portal. Actual business names, addresses, photographs, source brochures and signed documents must never be committed.

See [docs/SECURE_LISTINGS_SETUP.md](docs/SECURE_LISTINGS_SETUP.md) for the required Cloudflare Access, D1 and private R2 production configuration.
